# Contributing

## Suggest a wallpaper

[Open an issue](https://github.com/justcarlson/omarchy-wallpapers/issues/new?template=suggest-a-wallpaper.yml)
with a link to the original image and the theme it suits. The sets are
edited upstream and synced into this repository, so an issue is faster than a
pull request that edits `wallpapers.tsv`.

A good suggestion:

- links the original, not a resized copy or a Pinterest pin;
- is at least 2560 pixels wide;
- has a known creator or source, so it can be credited;
- has colours that sit close to the theme's own palette.

## Work on the installer or the gallery

The installer is [`install.sh`](install.sh), one Bash script. Everything else
is generated by `gallery`, a small Rust program in [`src/`](src). The Rust
version is pinned in [`mise.toml`](mise.toml).

```sh
mise install
cargo test                # unit tests and installer tests against a fake home
cargo run -- check        # the manifest, blueprints, previews and pages agree
shellcheck install.sh
```

`cargo test` runs `install.sh` end to end in a temporary home directory, both
from a checkout and through `curl | bash` with a `file://` URL. It never
touches your own `~/.config/omarchy`.

### The gallery commands

| Command | What it does |
| --- | --- |
| `gallery sync <dir>` | Copy a curator's `themes.tsv` and `images/` into `wallpapers.tsv` and `images/` |
| `gallery build` | Download originals, extract Aether palettes, draw previews and mosaics, then render |
| `gallery render` | Rebuild `README.md`, `themes/*.md` and `docs/index.html` from the committed data |
| `gallery check` | Fail if any of the above is stale or missing; CI runs this |

`build` needs the [`aether`](https://github.com/omacom/aether) CLI and each
theme installed, because it reads the theme's `colors.toml`. It only redoes
wallpapers whose image changed; pass `--force` to redo all of them. Downloads
are cached by SHA-256, and `--cache <dir>` adds another cache to look in.

Edit the hand-written parts of `README.md` freely. `render` only replaces the
text between the `<!-- stats -->` and `<!-- gallery -->` markers.

### The manifest

`wallpapers.tsv` has one row per wallpaper:

```
theme  sha256  file  source
```

`file` is the name the installer gives it, always starting with `curated-`.
`source` is an HTTPS URL pinned to an exact commit, or a path under
`images/` for an image stored here. The installer refuses any file whose
SHA-256 does not match.
